🗺️ Baugesuche Kanton Zürich

Interaktive Karte der öffentlichen Baugesuche

Diese Anwendung zeigt die veröffentlichten Baugesuche der 65 Gemeinden im Portal-Export auf einer interaktiven Karte. Die Daten werden täglich automatisch vom Portal ebaugesuche.zh.ch aktualisiert.

🗺️ Zur Karte 📚 GitHub Repo

🗺️ Interaktive Karte

Alle Baugesuche auf einer Karte mit SwissTopo Hintergrund sichtbar

📍 Geocoding

Nur exakt zugeordnete Adressen erhalten einen Kartenpunkt

🔄 Täglich aktualisiert

Neue Baugesuche werden automatisch hinzugefügt

🔗 Direkte Links

Klick zum offiziellen Baugesuch-Detail

📱 Responsive

Funktioniert auf Desktop, Tablet und Mobile

🌐 Open Source

Code ist öffentlich verfügbar und erweiterbar

ℹ️ Über diese Karte

Datenquelle: portal.ebaugesuche.zh.ch

Technologie: Leaflet, Node.js, GitHub Actions
